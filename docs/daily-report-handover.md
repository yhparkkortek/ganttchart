설계는 `docs/daily-report-design.md`, 코드 지도는 CLAUDE.md 파일 맵.

## ⚠️ 사람이 해야 하는 일 — 이거 둘 안 하면 반쪽만 돈다

### 1. 백엔드 재시작 (제일 먼저)

`kortek_backend.py` 와 `nas_dsm.py` 를 고쳤다. **재시작 전까지는:**

| 증상 | 이유 |
|---|---|
| 📣 알림 확인 버튼이 "백엔드가 구버전입니다" | `/daily/tick`·`/daily/config` 가 **404** |
| 텔레그램으로 보내도 아무 일 없음 | 수신 틱이 아직 안 돈다 |
| 미작성 알림이 안 나감 | 알림 틱이 아직 안 돈다 |
| **다음 달(12월)** 보고 저장이 갑자기 실패 | `nas_dsm` 폴더 생성 버그(아래) 수정이 아직 안 먹음 |

재시작: 작업표시줄의 백엔드 창을 닫고 `kortek_backend.bat` 다시 실행
(또는 시작프로그램에 등록돼 있으면 로그아웃/로그인).

> 💡 **이번 달(11월)은 재시작 안 해도 돈다** — 월 폴더를 밑줄(`2026_11`)로 두어
> 버그를 피해 갔다. 12월이 되기 전에만 재시작하면 된다.

### 2. 👥 명단 채우기 (Daily Report 탭 ▸ 👥 명단)

명단이 없으면 **미작성 표시도, 텔레그램 입력도 동작하지 않는다**(쓴 사람만 보인다).

| 칸 | 뭘 넣나 |
|---|---|
| 계정id | **NAS 로그인 계정**(파일 이름에 쓰인다). 본인 것은 이미 채워져 있다 |
| 실명 | 한글 이름 |
| 별칭 | 간트 담당자 이름과 맞추는 말(쉼표). 비워도 된다 |
| 텔레그램 ID | 그 사람의 chat_id — **이게 없으면 알림도 입력도 안 간다** |
| 📣 | 알림·수신을 **담당할 PC 한 대**. ⚠️ 반드시 한 명만 |

chat_id 는 알람 설정의 기존 팀원 관리(`/telegram/members`)에 있는 값과 같다.
지금 등록된 팀원이 **1명뿐**이라 5명을 채워야 한다.

> ⚠️⚠️ 📣 를 여러 명에게 주면 **보고가 흩어진다** — 텔레그램 `getUpdates` 는 먼저 읽은
> 프로세스가 가져가 버려서, 팀원 PC 가 다 폴링하면 누구 PC 가 받을지 알 수 없다.

### ❌ 확인 못 한 것 (정직하게)

- **실제 AI 호출**(2단) — 테스트 브라우저 프로필에 AI 키가 없어 한 번도 못 돌렸다.
  키가 있는 평소 브라우저에서 [🤖 AI로 정리] 를 한 번 눌러 봐야 한다.
- **실제 텔레그램 왕복** — 백엔드 재시작 전이라 못 했다. 재시작 뒤 본인에게 한 줄 보내 보면 된다.
- 엑셀 출력·이슈 승격·자동 적립 — 코드와 하네스는 통과했지만 **버튼을 눌러보진 않았다.**

## 재시작 뒤 5분 점검 (순서대로)

1. Daily Report 탭 ▸ **📣 알림 확인** → "백엔드가 구버전" 이 **안 뜨면** 라우트가 산 것.
2. 👥 명단에 본인 + 팀원 chat_id 를 넣고 📣 를 본인에게. 저장.
3. 텔레그램에서 `@kortek_dev3_bot` 에게 아무 줄이나 보내기 → **1분 안에** 봇이
   "📔 … 일일보고" 로 되읽어 주면 수신이 산 것.
4. `휴가` 한 단어만 보내 보기 → 일 종류가 바뀌는지.
5. Daily Report 탭에서 그 내용이 보이는지.

안 되면 백엔드 창의 `[일일보고 …]` 로그를 먼저 본다.

## 알아둘 함정 (다시 밟지 않게)

- **NAS 폴더 이름이 숫자로 시작하면 안 만들어졌다** — `2026`·`202611`·`2026-11` 전부 실패,
  `2026_11`·`testfolder` 는 성공. 게다가 `ensure_folder` 가 **이미 있는 폴더에도** 매번
  `CreateFolder` 를 불러서, 한 번 만들어 둬도 계속 막혔다.
  → `name`/`folder_path` 를 **JSON 배열**로 보내게 고쳤다(`nas_dsm.py`). 재시작 뒤 적용.
- **메일 유래 판정은 표식이 아니라 칸 내용**(`[출처]`/`[핵심내용]`)으로 한다.
  같은 날 `_mailRaw`·`＊AI📧`·`_담당구분`·`_rowUid` 가 전부 날아간 걸 봤다(칸 내용만 살아남았다).
- **간트에 담당자 열이 없다**(12/12 실측). 역할(`_담당구분`)로 사람을 찾는다.
  `SAL`/`영업` 정규화와 쉼표 다중 담당자를 반드시 거칠 것.
- **"모르면 안 보낸다"** — 비근무일 파일이 없거나 낡으면 0건, 조회 실패해도 0건.
  읽기를 **전부 끝낸 뒤** 보낸다(섞으면 앞사람에게 이미 나간 뒤 멈춘다).

- 결재·승인 흐름, 근태 입력, 업무 행마다 📔 버튼, 팀 1파일 집계 원장.
