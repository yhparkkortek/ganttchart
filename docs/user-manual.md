# 📘 KORTEK PM 사용자 매뉴얼 — 베타 1.0

> 간트차트 · 메일 자동 분석 · 텔레그램 알림 · 일일/주간 보고 · 문서 작성을 한 화면에서 쓰는 사내 프로젝트 관리 앱입니다.
> 베타 1.0 (2026-11-21). 이 문서의 원본은 저장소 `docs/user-manual.md` 이고, Word 파일은 `tools/manual-to-docx.py` 로 만듭니다.
> ⚠️ 이 저장소는 외부에 공개돼 있어 사내 주소·협력사 도메인·사번·실제 제품명은 적지 않습니다. 주소는 담당자에게 받으세요.

## 0. 베타를 쓰기 전에

- **PC 에서만 씁니다.** 모든 데이터는 사내 NAS 에 저장되고, 그 길을 각자 PC 에서 도는 **백엔드 프로그램**이 맡습니다. 휴대폰에서는 앱 대신 **텔레그램 봇**으로 보고·질문·알림을 씁니다([7장](#7-텔레그램으로-하는-일)).
- **백엔드가 꺼져 있으면 프로젝트를 아예 못 엽니다.** 화면이 비어 보이면 가장 먼저 백엔드가 떠 있는지 봅니다([10장](#10-자주-막히는-곳)).
- 로그인 실패는 **자동으로 다시 시도하지 않습니다.** NAS·SAP·그룹웨어·인사관리·JIRA 전부 같습니다 — 자동 재시도가 사내 계정을 잠그기 때문입니다. 막히면 비밀번호를 확인하고 백엔드를 다시 시작하세요.
- **AI 는 각자 본인 키**를 쓰고, 무료 키는 하루 한도가 있습니다. 한도를 넘기면 분석·요약이 멈춥니다(앱의 다른 기능은 그대로 됩니다).
- 베타에서 **아직 확인되지 않은 것**은 [11장](#11-베타에서-알려진-제한)에 따로 모았습니다. 거기 적힌 기능은 쓰기 전에 한 번 확인해 주세요.

## 1. 시작하기

### 1-1. 처음 설치 (PC 마다 한 번)

1. 앱 화면 ⚙️ 설정 ▸ **📧 메일·메신저 서버 설정** ▸ 맨 위 **📥 처음 사용자 — 설치 안내** ▸ **🚀 한 번에 설치 (권장)** 의 **[⬇️ 설치 파일 받기]**. 브라우저는 **Chrome** 을 권장합니다.
2. 받은 설치 파일(`KORTEK_설치.bat`)을 더블클릭합니다. 크롬이 경고하면 **[유지]** 를 누릅니다. Python 설치 → 백엔드 받기 → **시작프로그램 등록** → 연결 확인까지 자동입니다.
3. 끝나면 백엔드가 최소화된 창으로 떠 있고, PC 를 켤 때마다 자동으로 다시 뜹니다.

> 설치 파일에는 NAS 주소가 같이 들어 있습니다(앱에서 내려받을 때 끼워 넣습니다). 그래서 다음 단계의 로그인 화면에 **주소 칸이 보통 안 보입니다**.

### 1-2. 시작 화면 로그인

앱을 열면 회사 로고와 **아이디 · 비밀번호** 두 칸이 보입니다. **NAS 계정**(사내 파일 서버 계정)을 넣습니다.

- **계정 저장** 을 켜 두면 다음부터 자동으로 들어옵니다.
- **NAS 주소** 칸은 이 PC 에 설정이 하나도 없을 때만 나타납니다(새 PC). 담당자에게 받은 주소를 넣으면 앱 폴더까지 스스로 찾습니다.
- ⚠️ **비밀번호를 세 번 틀리면 이 PC 의 접속이 NAS 에서 막힙니다.** 남은 횟수를 화면에 보여 주고, 막히면 푸는 방법도 적어 줍니다. 자동으로 다시 시도하지 않으니 비밀번호를 확인하고 천천히 넣으세요.
- 상단 오른쪽 **👤 이름** 배지가 지금 로그인한 사람입니다. 누르면 **로그아웃**할 수 있습니다. 한 PC 를 여러 사람이 쓸 때(회의실 발표) **사람이 바뀌면 화면이 새로고침**됩니다 — 앞사람 화면의 자동저장이 뒷사람 계정으로 나가지 않게 하기 위해서입니다.

> 로그인한 계정이 **일일보고 파일 이름**과 **"내 프로젝트" 판정**의 기준이 됩니다. 남의 계정으로 들어가면 남의 이름으로 보고가 저장됩니다.

### 1-3. 앱을 열면

- 백엔드가 켜져 있고 로그인돼 있으면 **프로젝트 불러오기 창이 한 번** 뜹니다. 목록은 **팀 ▸ 담당자 ▸ 프로젝트** 3단으로 접혀 있고, 프로젝트 줄을 누르면 열립니다.
- 팀 줄 오른쪽의 **"전체 N개 열기"** 를 누르면 그 팀 프로젝트를 한꺼번에 엽니다.
- 열린 프로젝트는 **1분마다 자동 저장**됩니다. 상단 가운데의 **파일 이름을 클릭**해도 저장됩니다.
- 프로젝트를 둘 이상 열면 상단에 **시트 탭 줄**이 생겨 프로젝트 사이를 오갑니다.
- 엑셀 파일을 화면 아무 데나 **끌어다 놓으면** 프로젝트 엑셀로 읽어 병합합니다(메뉴에 엑셀 항목은 따로 없습니다).

### 2-2. 왼쪽 사이드바 — 탭

왼쪽 위 **☰** 로 사이드바를 접었다 폅니다. 마지막에 보던 탭을 기억했다가 다음에 그 탭으로 엽니다.

기본 순서는 아래와 같고, **탭을 끌어서 순서를 바꿀 수 있습니다**(이 PC 에 저장). 탭 이름과 각 페이지 제목은 **🌐 ENG** 로 영어로 바뀝니다(괄호 안이 영어 이름).

| 탭 | 하는 일 |
|---|---|
| 📒 **프로젝트 목록** (Project list) | 제품(모델) 전수 목록. 팀별로 관리 |
| 📝 **프로젝트 개요** (Summary) | 프로젝트 개요 · 담당자 · 모델 카드 · 개발 단계 일정 |
| 📐 **고객 사양** (Customer SPEC) | 고객 사양. **모델(제품구분자)별로 따로** 보관 + 지원 해상도 |
| 🧱 **BOM** | SAP BOM 다단계 전개 |
| ⚡ **부품** (PARTS) | 주요자재 구분별 비교표(PANEL · AD BD · CONV · TOUCH CTRL · TSP/GLASS …) |
| 💰 **재료비(M.C)** (M.C Table) | 원가 · 견적표 (R1 / R2 … 리비전별) |
| 📄 **문서** (Document) | Sample Report · DR/DVR 발표자료 · 라벨사양서 · 모델명세서 작성 |
| 🪐 **JIRA** | 이슈 트래커 연결 · 조회 · 댓글 · 새 이슈 |
| 📊 **간트차트** (Gantt chart) | 일정 본체 (처음 열리는 탭) |
| 📅 **캘린더** (Calendar) | 월간/주간 달력 (+ 그룹웨어 일정) |
| 📋 **주간 보고** (Weekly Report) | 주간 업무 보고 (PPT) |
| 📔 **일일 보고** (Daily Report) | 일일 업무보고 — 사람 × 날짜. 텔레그램과 연결 |
| 🔔 **알람/공지** (Alarm/Notice) | 알람 · 공지 발송, 핀셋 알람 예약 |
| 🪪 **주소록** (Address) | 주소록 (팀 공용) — 텔레그램 ID 도 여기 |

### 2-3. 탭마다 오른쪽 위에 있는 공통 버튼

생김새는 같아도 **지금 보고 있는 탭의 데이터**를 다룹니다.

| 버튼 | 하는 일 |
|---|---|
| **📊 엑셀 저장** | 이 탭 내용을 엑셀로 내보냅니다 |
| **📂 불러오기** | 내보낸 엑셀을 고쳐서 다시 넣습니다 (**통째로 교체**, 옆에 ↩️ 되돌리기가 생깁니다) |
| **📁 NAS** | 이 탭 전용 사내 NAS 자료실(열기 · 올리기) |

- **인쇄는 브라우저 인쇄(`Ctrl+P`)** 입니다. 예전의 "인쇄 (PDF)" 버튼은 없앴고, 어느 탭에서든 `Ctrl+P` 를 누르면 지금 보는 탭이 인쇄용으로 준비됩니다.
- 📂 불러오기는 **우리가 내보낸 엑셀**은 바로 넣고, 다른 양식(PDF·남의 엑셀)은 **AI 가 매핑해 미리보기로 물어본 뒤** 넣습니다. Calendar · Weekly Report · Alarm 처럼 다른 탭에서 만들어지는 화면에는 불러오기가 없습니다.
- ⚠️ **내보내기 전에 그 탭을 한 번 열어 두세요.** PARTS 처럼 화면을 보고 표를 만드는 탭은 한 번도 들르지 않으면 내용이 덜 나옵니다.

### 2-4. 아래쪽 작업표시줄

모달 창을 **최소화(—)** 하면 화면 아래 칩으로 내려갑니다. **💬 AI 문답 · 📧 AI 업무 분석 · 📦 AI 업무 보관함 · 🤖 AI 요약** 네 개는 항상 거기 있고 ✕ 로도 사라지지 않습니다 — 한 번 열면 언제든 그 칩으로 되돌아옵니다. 모달은 제목을 잡아 **끌어 옮기고**, 테두리를 잡아 **크기를 바꿀** 수 있습니다.

## 3. 프로젝트 다루기

### 3-1. 새 프로젝트

📁 프로젝트 ▸ **➕ 새 프로젝트 추가** → 마법사.

- **🚀 자동으로 가져오기** — 사내 NAS 의 **참조 엑셀**을 바로 불러와 화면에 반영합니다. Gantt · Summary · M.C Table 의 **열 구조가 이때 잡히므로** 건너뛰지 마세요.
- **📥 참조 엑셀 다운로드** — 직접 작성하고 싶을 때. 채운 뒤 화면에 끌어다 놓으면 같은 결과입니다.
- 참조 엑셀은 NAS 의 파일 한 개입니다. 서식을 고치려면 그 파일만 고치면 전원에게 반영됩니다.

### 3-2. 열기 · 저장 · 복원

- **열기** 📁 ▸ 📂 프로젝트 열기 / **저장** 📁 ▸ 💾 또는 상단 파일 이름 클릭 / **자동 저장** 1분마다.
- **🔄 프로젝트 복원** — 저장할 때마다 쌓인 백업 시점 목록에서 되돌립니다. 목록에 날짜 · 담당자 · 테마색이 함께 보입니다.
- 프로젝트의 **고객사 · 프로젝트명 · 인치**가 파일 이름의 재료입니다. 이 값을 고치고 저장하면 파일 이름이 바뀌지만, 목록의 담당자 · 팀 · 색은 그대로 따라옵니다.

### 3-3. 변경 이력

- Gantt 표 아래 **▶ 🕒 변경 이력 확인** — 누가 · 언제 · 무엇을 바꿨는지. 같은 박스가 Summary · Customer SPEC · M.C Table · Address · PARTS · Panel Compare 에도 있습니다.
- **🗑️ 구간 삭제** — 날짜 구간 + **관리자 비밀번호**. 되돌릴 수 없습니다.

### 3-4. 모델(제품구분자) — 한 프로젝트 안의 여러 제품

한 프로젝트에 MVD / TVD / TPR 처럼 **모델이 여럿**일 수 있습니다. Summary 의 **+ 모델 추가**로 늘리고, 그 뒤로는 Customer SPEC · M.C Table · BOM · Document · JIRA · 지원 해상도가 **모델마다 따로** 저장됩니다. 각 탭 위쪽의 **모델 바(◀ 모델 ▶)** 로 바꿉니다. 모델을 하나도 안 늘린 프로젝트는 모델 바가 아예 안 보이고 예전처럼 하나로 움직입니다.

## 4. 📊 Gantt chart

### 4-1. 기본 편집

- 업무명 왼쪽 **▶** 로 하위 업무를 접고 폅니다. 레벨(WBS)은 L0 개발단계 → L1 → … L4.
- 칸을 **더블클릭**하면 고칩니다. 키보드만으로 셀을 옮겨 다니며 편집할 수 있습니다 → [부록 A](#부록-a-키보드-단축키).
- 왼쪽 **⠿ 손잡이**로 행을 끌어 옮깁니다.
- 많은 행을 펼친 큰 프로젝트도 **보이는 만큼만** 그리므로 빠릅니다(스크롤하면 채워집니다).

### 4-2. No. 칸 — 행 메뉴와 핀셋 막대

- **No. 숫자를 클릭**하면 행 메뉴가 열립니다: **▲ 위로 / ▼ 아래로 이동 · ◀ WBS 레벨 올리기 / ▶ 내리기 · ＋ 행 추가 / － 행 삭제 · 그룹으로 묶기**(2개 이상 선택했을 때) · **✅ 선택한 행 완료로**(하위 업무까지 한꺼번에, `Ctrl+Z` 로 되돌아옵니다). 메뉴가 열린 채로 키보드(↑↓←→ · + · - · Delete)로도 됩니다.
- No. 칸 **왼쪽의 세로 막대**가 **📌 핀셋(알람) 표시**입니다. 누르면 켜지고(테마의 보색) 다시 누르면 꺼집니다. 핀셋이 켜진 업무만 **Alarm/Notice 탭 · Calendar 📌 · Weekly Report 핀 모드**에 나옵니다.
- **상태 칸을 더블클릭**하면 하위 업무까지 완료로 바뀝니다.

### 4-3. 도구

- **🎛️ 업무필터 ▾** — LEVEL(WBS) · 업무상태 · 개발단계로 거릅니다.
- **🛠️ 일정 도구** — 🔓 선택 구간 재계산 · 📅 날짜순 정렬 · 📅 AI 분석 날짜로 복원(전체) · 🗂 그룹 제안 찾기 · 🧹 자동 정리(전체 진단) · ➕ 현재 일정을 새 계획으로 저장(저장한 계획을 누르면 비교, ⭐ 로 최초 계획(킥오프) 지정).
- 날짜 칸을 **클릭하면 달력**, **더블클릭하면** 그 그룹 날짜의 근거 행으로 이동합니다. 소요일 칸에서 `Space` 는 🔒 고정 / 🔓 자동 전환.
- **🔍 AI검색** — 간트 안 키워드 검색(`Ctrl+Shift+F`).
- 메일에서 들어온 업무는 상세내용에 `[출처]` `[핵심내용]` `[To do]` 가 적혀 있고 **📧 원문 보기**로 원본 메일을 볼 수 있습니다.

> 💡 **"지연" 판정에서 메일 업무는 뺍니다.** 메일 행은 "고객이 단가를 물었다 — 8/24" 같은 **사건**이지 누가 끝내는 업무가 아니라서, 늦었다고 세지 않습니다(아침 브리핑 · 밀린 업무 정리 · 일일보고 초안 모두 같은 규칙).

## 5. 탭별 사용법

### 📒 Project list

제품(모델) 전수 목록. **팀별로 따로** 관리됩니다.

- 헤더: **팀 선택** 드롭다운 · 검색칸 + 🔍 · **↺**(검색·필터·정렬 초기화) · **🔍 정보 확인**(프로젝트 파일과 값이 다른 행 표시) · 📊 엑셀 저장 · **📂 불러오기**(사내 "제품 SPEC" 엑셀 그대로, 또는 NAS 의 JSON) · 📁 NAS · **🔁 열**(숨긴 열 되돌리기).
- **열 묶음 체크박스** — 기본 / 담당 / 패널 / 광학 / 전원 / 주요자재 / 케이블 / 터치 / 기구·포장 / 인증 / 판매량. 체크한 묶음만 표에 나옵니다(열이 91개라 전부 띄우지 않습니다).
- **NO 숫자 클릭** — 위 · 아래 이동, 행 추가, 삭제, 📌 고정. 검색은 입력을 멈추면 걸러집니다.
- NAS 자료는 **PN(품번)** 으로 찾습니다 — 파일 이름에 그 번호가 들어 있으면 걸립니다. Agile REV 칸의 **📜** 로 도면의 REVISIONS · DISPLAY INFORMATION MATRIX 표만 잘라 봅니다.

### 📝 Summary

- 프로젝트 개요 · 수량 · 배경 · **개발 단계별 일정**(RFQ · PROTO A · PROTO DR · MP · ES · DVR · PRA …) · 프로젝트 멤버(역할별 담당자).
- 헤더의 **상태 선택(🔵 DV / 🟢 MP(EC) / 🔴 EOL)** — EOL 로 두면 프로젝트 목록에서 흐리게 보이고 새 메일 자동매칭 대상에서도 빠집니다. **🔄 Gantt 실적 연동** — Gantt 의 실제 일정을 단계 날짜로 끌어옵니다. 본문에 **+ 모델 추가 · + 인원 추가**.
- **모델 카드** — + 모델 추가. 카드의 **JIRA 코드** 칸에 JIRA 프로젝트 키를 적으면 JIRA 탭이 그걸로 이슈를 가져옵니다(🔍 찾기 버튼으로 바로 검색).
- **역할별 담당자 칸(PM · HW · FW · 기구 …)** 이 "누구 업무인가"의 기준입니다 — 아침 브리핑 · 일일보고 초안 · AI 요약 필터가 전부 여기서 사람을 찾습니다. **비워 두면 그 역할 업무는 아무에게도 안 갑니다.**

### 📐 Customer SPEC

- 위 모델 바로 제품구분자를 바꾸면 그 모델 사양으로 갈아낍니다. **🔽 펼치기**로 접힌 항목을 폅니다.
- **🖥 지원 해상도** — 표준 해상도 목록(VESA · CTA 포함)에서 포트별(RGB · DVI · HDMI · DP …)로 체크합니다. 표준에 없는 고객 요구 해상도는 **CUSTOMER RESOLUTION** 묶음에 **＋ 행 추가**로 적습니다. 모델마다 따로 저장되고, Document 의 RESOLUTION SPEC 이 이 선택을 그대로 씁니다.

### 🧱 BOM

- 헤더: 자재번호 입력칸 · **다단계 / 단일 레벨** · 레이아웃 선택 · **🔄 SAP 조회**(SAP GUI 가 떠 있어야 합니다) · **$ 환율** · **▸ 접기**(하위 전부 접기) · 📊 엑셀 저장(`C:\SAP_DMS\SAP조회` 에 저장).
- **▸ ▾** 로 계층을 접고 펴고, **행을 클릭**하면 그 부품을 조회합니다. 정렬은 **같은 부모 밑 형제끼리만** 바뀌어 모자 관계가 흐트러지지 않습니다.
- ⚠️ **화면과 엑셀은 같은 "지금 보이는 상태"** 입니다. 접어 둔 채 엑셀을 저장하면 접힌 그대로 나옵니다.
- ⚠️ 가져온 BOM 의 **계층이 깨졌다는 경고**가 뜨면 팀 공용 SAP 계정의 ALV 레이아웃에 누군가 정렬을 걸어 둔 것입니다. 화면이 어느 레이아웃 · 어느 정렬인지 적어 주니 그 레이아웃을 고치세요(레벨별 묶음으로 보여 줍니다).

### ⚡ PARTS

주요자재 구분(PANEL · TSP/GLASS · TOUCH CTRL · AD BD · CONV · BLU · POWER · METAL · MOLD · DIE CAST · SLIM CUT …)별 **비교표**. 왼쪽 위 드롭다운으로 구분을 바꿉니다.

- **▼ SPEC / ► BOM** 전환. 구분마다 **➕ 추가**(파일에서 읽어 오기 · **AI 로 추출** · 📁 NAS 에서 고르기) · **🔽 펼치기** · 📊 엑셀 저장. BOM 모드에선 **🔄 SAP 조회 · $ 환율**. 항목마다 **✏️ / 🗑**, 사진은 크게 보기(←→ 로 넘김).
- 부품명 옆 **📜 숫자** — 그 부품 이름으로 찾은 NAS 사양서 개수. 누르면 엽니다.
- 회사 **패널 비교표 엑셀**을 📂 불러오기에 넣으면 팀 공용 **패널 라이브러리**에 한 번에 들어갑니다(AI 없이).
- 사진은 **Ctrl+V 붙여넣기**로도 넣을 수 있습니다.

### 💰 M.C Table

- 헤더: ℹ️ 도움말 · **🔽 펼치기** · **➕**(새 리비전) · **R1**(누를 때마다 금액이 든 리비전끼리 순환) · **VS**(리비전 비교) · **금액삭제**.
- **➕ / ✏️ / 🗑️** 로 행을 더하고 고치고 지웁니다. ⚠️ **금액삭제**는 금액을 **전체** 지웁니다.
- 협력사 · 사내 **M.C 엑셀(R1 시트)** 을 📂 불러오기로 넣으면 AI 없이 읽어 **어느 모델에 넣을지 고르는 화면**이 뜹니다. 파일 이름의 괄호 모델명이 기존 모델과 맞으면 그 모델을 제안합니다.

### 📅 Calendar

- **월 / 주** 전환, **◀ 이전 / 다음 ▶ / 오늘**, **LEVEL(WBS) ▾**, **📌 핀셋 업무**.
- **🏢 그룹웨어 일정 / 📊 Gantt 일정** 토글 — **버튼 글자가 "지금 보고 있는 것"** 입니다. `🏢 그룹웨어 일정`이라고 적혀 있으면 지금 그룹웨어 일정을 보는 중이고, 누르면 간트 업무로 바뀝니다. 건수는 버튼에 마우스를 올리면 보입니다.
- **📤 내보내기/동기화** — `📤 ICS 내보내기 (1회성)` / `🔗 지금 동기화 실행 (자동)`.

### 📋 Weekly Report

- **◀ 이전주 / 다음주 ▶ / 오늘**, **LEVEL(WBS) ▾**, **📌 핀셋 업무**(핀셋 업무만 / 레벨로 보기 전환).
- 주는 **월요일 ~ 일요일**입니다(베타 1.0 에서 금요일 → 일요일로 바꿨습니다. AI 요약의 주와 같습니다).
- 상세내용의 `[문제점]` `[대책]` 줄이 아래 이슈 표로 모입니다(여러 줄이어도 끝까지 읽습니다).
- **📥 PPT 출력** — ① 🎨 테마 색상 고르기 ② ✍️ 내용 미리보기(고칠 수 있는 칸, AI 키가 있으면 다듬어 줍니다) ③ **💾 PPT 저장**. "취소 (직접 출력)" 은 이름과 달리 **원본 그대로 출력**합니다 — 진짜로 그만두려면 ✕.

### 📔 Daily Report (일일 업무보고)

사람 × 날짜로 저장되는 하루 보고입니다. 텔레그램으로도 쓸 수 있습니다([7장](#7-텔레그램으로-하는-일)).

- 헤더: **◀ 이전날 / 다음날 ▶ / 오늘 · ✏️ 내 보고 쓰기 · 👥 명단 · 📣 알림 확인 · 🗓️ 월 보기 · 📊 엑셀 출력**.
- **✏️ 내 보고 쓰기** — 업무마다 **오늘 한 일 / 해야 할 일 / 막힌 일** 세 칸 + 업무 구분(HW · FW · 기구 …) + 프로젝트. **일 종류**(근무 · 휴가 · 반차 · 출장 · 교육)를 고르면 그걸로 끝낼 수도 있습니다.
  - **간트에서 불러오기** — 내가 맡은 업무(열린 프로젝트뿐 아니라 **내 팀 프로젝트 전부**)를 후보로 보여 줍니다. 메일 분석이 적어 둔 `[핵심내용]` `[To do]` 가 초안이 됩니다(AI 호출 없음).
  - **🤖 AI 로 정리** — 하루 1회, 초안을 다듬어 미리보기로 보여 줍니다.
  - **📎 사진 · 파일** — 고르기 · 끌어놓기 · **Ctrl+V** 캡처. 업무 카드에 떨어뜨리면 그 업무에 붙습니다.
  - 오늘 변경된 **연결 JIRA 이슈**를 참고 칸에 보여 줍니다(보고에 자동으로 들어가진 않습니다 — 직접 옮겨 적습니다).
- 하루 보기는 **이름 | 종류 | 구분 | 업무 | 오늘 한 일 | 해야 할 일 | 막힌 일 | 첨부** 한 겹 표입니다. 담당자 · 프로젝트 · 구분 필터가 있고, **내 행은 더블클릭**으로 바로 고칩니다. 60초마다 조용히 갱신됩니다.
- **👥 명단** — 이 표에 누가 나오는지, 누가 📣 **알림 담당 PC** 인지(반드시 한 명), 아침 브리핑 시각, 그리고 **📋 알림 채널 상태판**([7-6](#7-6-알림이-안-올-때--알림-채널-상태판)). 사람 목록은 주소록에서 자동으로 채워지고 여기선 📣 · 사용 안 함 · 별칭만 손봅니다.
- 보고를 지우려면 항목을 전부 ✕ 로 빼고 저장합니다(빈 보고를 남기지 않고 파일을 지웁니다).

### 📄 Document

문서를 고르면 **그 서식이 그대로 화면**이 되고, 기본 정보는 앱에서 자동으로 채워지며 나머지를 적어 출력합니다. AI 는 쓰지 않습니다.

- 헤더 드롭다운으로 문서를 고릅니다: **📑 Sample Report (시제품) · 📊 DR / DVR 발표자료 · 🔖 라벨사양서 · 📘 모델명세서**. (시제품 제작의뢰서는 Sample Report 안에 들어 있어 목록에서 숨겼습니다.)
- **자동값과 직접 쓴 값** — 칸마다 **출처**(📘 Summary ▸ 프로젝트 멤버 처럼)가 보입니다. 자동값은 저장하지 않아 앱 값이 바뀌면 문서도 따라가고, 사람이 고친 값만 남으며 **↺ 앱 값으로**로 되돌립니다.
- **모델 바** — 모델마다 문서가 따로입니다(M.C · BOM 과 같은 모델).
- **📦 회차 바** — Sample Report 는 **샘플 출고 이력의 회차마다** 문서가 따로 생깁니다(PROTO A · PROTO A 2차 · PROTO B …). **＋ 단계 추가 / ＋ 회차 추가**. 출고 이력은 문서 맨 위 구역이고 지금 보는 회차 줄에 표시가 붙습니다.
- **🏷 리비전 바(R1 · R2 …)** — 라벨사양서 · 모델명세서는 M.C 처럼 리비전을 둡니다. ➕ 는 이전 리비전을 복사할지 묻고, **🆚 VS 비교**가 리비전 사이에 뭐가 늘고 줄고 바뀌었는지 문장과 표로 보여 줍니다.
- 헤더: **📄 문서 ▾**(문서 고르기) · 모델/회차/리비전 **◀ ▶** · **✏️** 이름 바꾸기 · **➕** 추가 · **🗑️** 삭제 · **📦 출력** 메뉴(**📗 엑셀 저장 · 💾 원본저장**(.docx/.xlsx — 실제 사내 양식 파일에 값만 채운 것) · **PPT 저장**(DR 자료) · **NAS** 로 올리기 · **📂 불러오기**). 인쇄는 `Ctrl+P`.
- **📂 불러오기** — 라벨사양서 엑셀(모델명세서_라벨 양식)을 넣으면 라벨 · 인증 표를 읽어 채웁니다.
- 라벨사양서의 **🔎 도안 찾기** — 라벨품목코드 · 규격으로 사내 SAP 문서 폴더를 뒤져 도안 이미지를 고르고(여러 장이면 사람이 고릅니다) 크기 · 자르기 · 회전 · 번호 표시를 붙입니다. 도안은 **코드별 공용 자료**라 다른 프로젝트도 같은 코드면 바로 보입니다. SAP 에 새로 등록된 도안은 **🔄 SAP 에서 다시 받기**를 눌러야 들어옵니다.
- **SPL Check sheet**(Sample Report 안) — 점검 칸을 **눌러 O** 를 켭니다. Resolution 장은 Customer SPEC 에서 고른 해상도만 나옵니다. 점검요청 켠 것만 보기 접기/펼치기가 있습니다.
- 첨부(사진)는 **끌어놓기 · Ctrl+V**, 사진을 클릭하면 번호 핀 + 설명을 붙입니다.

### 🪐 JIRA

사내 Kortek Issue Tracker 를 앱 안에서 봅니다. 계정은 ⚙️ 🔑 로그인·저장소 설정 ▸ JIRA.

- **연결** — Summary 모델 카드의 **JIRA 코드**(프로젝트 키)가 기본입니다. 탭에 들어오면 그 프로젝트의 이슈를 자동으로 가져옵니다. 🔗 수동 키 · 🔍 검색어 · 📧 메일에서 잡힌 이슈번호는 **🔎 더 찾기**를 눌러야 조회됩니다(자동으로 섞으면 다른 모델 이슈가 끼어듭니다). **모델마다 따로** 연결됩니다.
- 헤더: **🆕 새 이슈 · 🔄 새로고침 · ⚙️ 연결 설정**. 표 아래 **🔎 더 찾기**. 표 머리글에서 **정렬 · 필터**(상태 · 담당자 · 우선순위 · 출처 · 키/요약 검색). NO. 번호로 AI 문답에서 "A8 대화 5번" 처럼 가리킬 수 있습니다.
- 행을 누르면 **상세 모달** — 댓글(대응) 등록 · 수정 · 삭제, 상태 전환, 요약/담당자/우선순위 수정, 구성요소 · 해결책 · Milestone, **📎 첨부 저장**(끌어놓기 · Ctrl+V) · 연결 프로그램으로 열기, **📋 간트 업무로 등록**.
- **🆕 새 이슈** — 지금 모델의 JIRA 연결이 있을 때만. 담당자 🔍 찾기.
- ⚠️ 로그인에 한 번 실패하면 재시도하지 않습니다(계정 잠금 방지).

### 🔔 Alarm/Notice

- 핀셋을 켠 업무가 **알람 목록**에 모입니다. 행을 눌러 **D-day 알람 일정**(기본값/커스텀 D-N)을 정하고, **⏰ 기간·반복 예약**을 걸면 그 PC 의 백엔드가 **정한 날짜·시각에 메일 + 텔레그램**으로 보냅니다(담당자 · 수신인 · CC).
- 헤더 **🔔 Alarm ▾** 로 Alarm / Notice 를 오갑니다. **📧 일괄 발송**(미발송분 전체) / **📤 선택 발송**(선택했을 때만 보임) — 지금 바로 보냅니다.
- **Notice** — D-day 알람과 별개인 **반복 공지**. **+ 공지 등록 · 📢 전체 즉시 발송 · 🗑️ 선택 삭제**. 기간 · 요일 · 시각을 정해 두면 그 PC 의 백엔드가 보냅니다.
- 보내는 메일 계정 · 텔레그램 봇 · 외부 도메인 허용은 ⚙️ 설정 ▸ **📧 메일·메신저 서버 설정**.
- ⚠️ 기간·반복 예약은 **등록한 그 PC 의 백엔드가 켜져 있을 때만** 울립니다(규칙이 PC 에 저장됩니다). 발송 결과는 [알림 채널 상태판](#7-6-알림이-안-올-때--알림-채널-상태판)에 남습니다.

### 🪪 Address

| 기능 | 어디서 | 설명 |
|---|---|---|

| **AI 업무 보관함** | 🤖 AI 도구 ▸ 📦 | 자동 배치되지 않은 업무가 모입니다. 여기서 프로젝트로 보냅니다 |

### 6-1. AI 분석 설정 (🤖 AI 도구 ▸ ⚙️)

- **🤖 AI 모델 선택** — 제공사(Gemini / Groq / Mistral / OpenRouter / OpenAI)와 모델, **API 키**(🔗 발급받기). 🟢 무료 / 🟡 무료(제한) / 🔴 유료 표시.
- **🔢 AI 글자 수** — 한 번에 몇 자까지 보낼지. **🔄 기본값** 버튼.
- **🔀 교차 폴백** — 한 제공사가 한도에 걸리면 다른 곳으로.
- **재분석** — 실패한 건을 바로 다시 할지 모았다 할지(기본은 꺼짐 — 무료 한도를 아낍니다).

### 6-2. 메일 → 업무 등록 (핵심 흐름)

```
메일  →  🤖 AI 업무 분석  →  📦 업무 보관함  →  프로젝트의 간트
```

1. **🤖 AI 업무 분석**에 메일을 넣습니다 — **✏️ 직접 입력**(본문 붙여넣기) / **📂 파일 첨부**(.eml · PDF · 엑셀) / **🌐 메일 서버**(사내 메일함에서 바로, 자동 수집도 여기). **✏️ 프롬프트**로 AI 지시문을 고칠 수 있습니다(팀 공용).
2. 결과를 **[📥 보관함]** 으로 담으면 프로젝트와 독립적으로 보관됩니다.
3. **📦 업무 보관함**에서 보냅니다 — **➡️ 현재 프로젝트** / **📤 다른 프로젝트**(화면을 바꾸지 않고 그 파일로 직접) / **🚀 매칭건 일괄전송** / **🧹 저장공간 정리**.
   - 카드마다 **❌ 오매칭 / ♻️ 중복 / 🚫 불필요** 아이콘이 있어 한 번 누르면 **학습 기록 + 삭제**가 같이 됩니다. 묶음 삭제는 확인창 없이 **취소 칩**이 잠깐 뜹니다.

**어느 프로젝트로 가나(자동 배치 규칙)** — 메일의 **고유 식별자**(모델명 · 관리번호 · 고객 모델명)가 한 프로젝트만 가리키면 자동 배치, 같은 **가족**(고객 · 프로젝트가 같은 형제 모델들)만 확정되고 모델 단서가 없으면 **가족 대표**로, 그마저 없으면 AI 가 자신 있을 때만, 나머지는 **대기**입니다. 같은 제목 스레드 · 답장 관계도 근거로 씁니다. 틀리게 간 것을 ❌ 오매칭으로 지우면 그 교정이 기록돼 같은 스레드가 다시 그리로 가지 않습니다.

- 가족 대표 지정 · 대기 재판정 · 자동 기능 스위치는 ⚙️ 설정 ▸ **📬 메일 자동배치 설정**([8-3](#8-3-메일-자동배치-설정)).

## 7. 📱 텔레그램으로 하는 일

### 7-1. 준비 (한 번)

1. 사내 봇에게 아무 말이나 한 번 보냅니다(대화가 열려야 봇이 보낼 수 있습니다).
2. 내 **텔레그램 ID** 가 🪪 Address 주소록에 들어 있어야 합니다. 일일보고 **👥 명단**은 주소록에서 자동으로 채워집니다.
3. 팀에서 **📣 알림 담당 PC 한 대**를 정합니다(👥 명단의 📣 라디오). 그 PC 의 백엔드가 봇 메시지를 받고 미작성 알림 · 아침 브리핑을 보냅니다. **반드시 한 명** — 여러 대가 받으면 메시지를 서로 빼앗습니다.

### 7-2. 일일보고를 폰에서 쓰기

봇에게 **그냥 적어 보내면** 오늘 보고로 저장됩니다. 서식:

```
회로 검토
한일: 1차 검토 완료, 결과 공유
할일: 2차 검토
막힌일: 샘플 미입고

휴가            ← 한 단어만 보내면 그 날 종류로 끝
/다시           ← 오늘 글 지우기(사진은 안 지움)
```

- 첫 줄이 **업무 이름**, 그 아래 `한일:` `할일:` `막힌일:`(또는 `오늘 한 일` `해야 할 일` `막힌 일` `이슈` 등). 태그가 먼저 오면 **마지막 업무**에 붙습니다.
- **사진 · 문서**를 보내면 첨부로 붙고, 설명 글(caption)이 업무 한 줄이 됩니다.
- 저장되면 봇이 **되읽어** 줍니다. 질문처럼 보이는 글을 보냈을 땐 "질문이었나요?" 안내가 한 줄 붙습니다.

### 7-3. AI 문답을 폰에서

- 앞에 **`/ai`** 를 붙입니다: `/ai 999001 재고 확인해줘` · `/ai 이번 주 마감 업무` · `/ai 최근 메일 요약` · `/ai 오늘 보고 초안`.
- **`/문답`** 을 한 번 보내면 그 뒤로는 접두어 없이도 질문으로 받습니다(3시간 뒤 또는 **`/보고`** 로 보고 모드로 돌아옵니다). 문답 모드라도 `한일:` 태그 · `휴가` · `/다시` 는 보고로 갑니다.
- 답은 **PC 에 켜 둔 앱**이 만듭니다. 앱이 꺼져 있으면 "앱이 꺼져 있는 것 같다"고 답하고, 열면 그때 처리합니다. 확인 버튼이 필요한 일(자재청구 등)은 "PC 에서 눌러 달라"고 답합니다.
- **`/ai 오늘 보고 초안`** — ① 안내 ② **복사용 글** 두 통이 옵니다. ②를 고쳐 접두어 없이 보내면 그대로 저장됩니다.
- `/help` (또는 `도움말`) — 사용법. `/ai` 대신 `/질문` `/검색` `질문:` `?` 로 시작해도 됩니다.

### 7-4. 대기 메일 배분 — `/배분`

(`/대기` `/메일배분` `대기 메일` 도 같은 말) 보관함에 **대기**로 남은 메일(후보 프로젝트가 있는 것)을 폰에서 버튼으로 보냅니다. 메일 한 건에 한 통(제목 · 보낸이 · 후보)과 `→ 1) 프로젝트` 버튼 · `⏭ 보류`. 실행은 PC 의 앱이 하고 ✅/❌ 를 다시 보냅니다. 한 번에 5건, 끝나면 `/배분` 을 다시.

| 📌 **즉시 알람 · 📢 공지** | 알람 탭에서 사람이 보낼 때 | 그 PC |

- `/브리핑` 을 보내면 아침을 기다리지 않고 지금 내 브리핑을 받습니다. 👥 명단 ▸ **📱 내게 미리보기**도 같습니다.
- 브리핑의 "내 업무"는 Summary 의 역할별 담당자 칸으로 가립니다. 엉뚱한 업무가 오면 그 칸과 명단의 별칭을 확인하세요.

### 7-6. 알림이 안 올 때 — 📋 알림 채널 상태판

📔 일일 업무보고 탭 ▸ **👥 명단** ▸ 아래 **📋 알림 채널 상태판**. 채널 다섯 개(예약 발송 · 새 메일 알림 · 텔레그램 수신 · 미작성 알림 · 아침 브리핑)의 **지금 상태 · 마지막 발송 · 마지막 확인 · 설정**을 한 표로 보여 줍니다. 맨 윗줄에 이 PC 가 📣 담당인지, 봇 토큰 · NAS 연결 · 명단 인원 · 오늘이 비근무일인지가 있습니다.

| 상태판 문구 | 뜻 | 할 일 |
|---|---|---|
| 📣 담당 PC 아님 → 홍길동 | 이 PC 는 보내는 PC 가 아닙니다 | 홍길동 PC 에서 상태판을 봅니다 |
| 📣 담당이 아무도 없음 | 명단에 📣 가 없어 세 채널이 전부 멈춤 | 명단에서 한 명 지정 |
| 아직 발송 시각 전 / 마감 시각 전 | 정상 | 기다립니다 |
| 비근무일 — 안 보냄 | 주말 · 공휴일 | 정상 |
| 꺼짐 | 새 메일 알림이 설정에서 꺼짐 | 📧 메일·메신저 서버 설정에서 켭니다 |
| ⚠️ 그룹웨어 로그인 필요 | 새 메일 알림은 그룹웨어 세션이 있어야 함 | 앱에서 그룹웨어 로그인 1회 |
| ⚠️ 봇 토큰 없음 | 이 PC 백엔드에 텔레그램 설정이 없음 | 📧 메일·메신저 서버 설정 ▸ 메신저 |
| ⚠️ (규칙 이름): 텔레그램 id 가 있는 담당자/수신인 없음 | 핀셋 알람을 보낼 사람이 주소록에 없음 | 🪪 Address 에 텔레그램 ID 입력 |
| 백엔드가 구버전입니다 | 재시작이 필요 | 백엔드 창을 닫고 다시 실행(또는 PC 재부팅) |
| 로컬 백엔드에 연결하지 못했습니다 | 백엔드가 꺼짐 — 이 PC 에선 어떤 알림도 안 나감 | 백엔드 실행 |

> 상태판은 **그 PC 의 백엔드가 본 것**만 보여 줍니다. 미작성 알림 · 브리핑 · 텔레그램 수신은 📣 담당 PC 에서 열어야 실제 상태가 보입니다.

### 8-2. 메일·메신저 서버 설정

네 구역으로 접혀 있습니다(▶ 펼치기).

- **📥 처음 사용자 — 설치 안내** — 설치 파일 받는 곳.
- **🖥️ 이메일 서버 설정** — 서버 주소 / 포트 / 계정 / 비밀번호 / **받는 서버**. ⚠️ 보내는 서버와 받는 서버는 다른 장비일 수 있습니다(받는 서버를 비우면 기본값). IMAP 권한이 없으면 **"수신은 POP3만 사용"** 체크. 같은 통합 계정이라 **그룹웨어 자동 로그인에도 같이 저장**됩니다.
- **💬 메신저 서버 설정** — 텔레그램 Bot Token / 내 Chat ID / 수신자. **📧 새 메일 알림** 켜기 · 확인 간격 · 조용한 시간 · **지금 보내보기**.
- **🌐 외부 도메인 발송 허용** — 사외 도메인으로의 발송을 도메인 단위로 허용.

### 8-3. 메일 자동배치 설정

- **⏱️ 수집설정** — 수집 주기, 📌 핀셋 기준점수, EOL 포함 여부, 처리된 업무 자동삭제, 토픽 프로파일 자동 생성.
- **⭐ 가산점수** — 🚨 키워드 점수 · 📊 우선순위 점수(외부 발신 · To · Cc · 중요도) · 👤 직급별 점수.
- **🚫 자동폐기 필터** — 아예 버릴 메일 조건.
- **🧭 배분 판정 · 자동 동작** — **가족 대표**(형제 모델 묶음마다 "모델 단서가 없는 메일은 이 모델로"), **🧭 대기 중인 보관함 항목 지금 재판정**(AI 없이 지금 규칙으로 다시 보고 자동 조건이면 배치), **자동 동작 스위치**(군집 감지 · 오염 진단 · 재시도 엔진 · 키워드 자동 누적 등 — 기본 꺼짐, 무료 한도를 아끼고 오배송을 줄입니다), 🧹 색인 다이어트.

### 8-4. 🔑 로그인·저장소 설정

- **NAS** — 계정 · 앱 폴더 · 자료실 경로. 🚀 간편 전환이 로그인 → 앱 폴더 찾기 → 자료실 경로까지 밟습니다. 연결 테스트는 비밀번호를 새로 받지 않습니다(실패를 쌓지 않으려고).
- **SAP** — 자동 로그인 계정(비밀번호는 이 PC 에만 암호화 저장). 실패하면 재시도 없음.
- **그룹웨어** — 전용 크롬으로 1회 자동 로그인. 메일 계정과 같은 계정.
- **인사관리 · JIRA** — 같은 규칙(1회 실패 후 잠금).

## 11. 베타에서 알려진 제한

**쓰지 말거나 확인 뒤 쓸 것**

- **전자결재 기안 작성** — 실제 작성 화면에 값이 들어가는 것 미확인(6-7). 베타 범위 밖.
- **핀셋 기간·반복 알람의 실제 텔레그램 수신** — 저장소 이사 뒤 읽는 길을 고쳤고 하네스로는 통과했지만, 실제 폰으로 받는 것은 회사에서 한 번 확인이 필요합니다(2026-11-21).
- **아침 브리핑 · 미작성 알림 · `/배분` · `/ai 오늘 보고 초안` 의 실제 폰 왕복** — 코드와 하네스로만 확인.
- **SAP 쓰기**(자재청구 MB21 · 구매오더 · 입고처리 ZMM062) — 실환경 검증은 일부(입고처리 1회)만.
- **인사관리 칸 채우기** — 설정 · 접근까지만 확인.

**설계상 그런 것**

- 기간·반복 알람 규칙은 **등록한 PC 에만** 저장되고 그 PC 가 켜져 있을 때만 울립니다.
- 📣 담당 PC 가 꺼져 있으면 텔레그램 수신 · 미작성 알림 · 브리핑이 전부 멈춥니다(여러 대가 받게 할 수 없습니다).
- 휴대폰 브라우저에서는 앱이 축소돼 보일 뿐 쓸 수 없습니다.
- 주간보고의 "N주차" 번호는 1월 1일 기준 계산이라 ISO 주차와 해에 따라 1주 다를 수 있습니다(2026년은 같음).
