## 1. 시작하기

### 1-1. 무엇이 필요한가

| 필요한 것 | 왜 | 없으면 |
|---|---|---|
| **백엔드가 켜져 있어야 함** (`kortek_backend.bat`) | 저장소(NAS)·메일·SAP·그룹웨어가 전부 이 프로그램을 거친다 | 프로젝트를 **아예 못 연다** |
| **NAS 계정** (사번·비밀번호) | 2026-11-04부터 데이터는 사내 NAS에 저장된다 | 프로젝트 목록이 비어 보인다 |
| **PC** | 백엔드가 PC에서만 돈다 | 📱 휴대폰에서는 쓸 수 없다 |

처음 설치는 설치 안내 맨 위 **[⬇️ 설치 파일 받기]** → 받은 `kortek_setup.bat` 더블클릭.

### 1-2. 처음 한 번만 — NAS 연결

1. 상단 **⚙️ 설정 ▸ 🔑 로그인·저장소 설정**
2. **NAS** 탭 ▸ **🚀 간편 전환**
3. 아이디·비밀번호 두 칸만 넣으면 계정 저장 → 로그인 → 앱 폴더 찾기까지 자동으로 진행된다.

> ⚠️ **비밀번호를 틀리면 3번까지만 시도한다.** 그 이상은 NAS가 이 PC의 접속을 막을 수 있어
> 앱이 먼저 멈춘다. 막혔다면 비밀번호를 확인한 뒤 백엔드를 다시 시작한다.

### 1-3. 앱을 열면

- 백엔드가 켜져 있고 NAS에 로그인돼 있으면 **프로젝트 불러오기 창이 자동으로 한 번** 뜬다.
- 목록은 **팀 ▸ 담당자 ▸ 프로젝트** 3단으로 접혀 있다. 프로젝트 줄을 누르면 열린다.

| **🤖 AI 도구** | AI 업무 분석 · AI 업무 보관함 · AI 요약 · AI 문답 · AI 분석 설정 |

### 2-2. 왼쪽 사이드바 — 탭 11개

> 생김새는 같아도 **그 탭의 데이터**를 다룬다.

## 3. 프로젝트 다루기

### 3-0. 새 프로젝트 만들기

📁 프로젝트 ▸ **➕ 새 프로젝트 추가** → 마법사가 뜹니다.

- **🚀 자동으로 가져오기** — 사내 NAS의 참조 엑셀을 바로 불러와 화면에 반영합니다.
  Gantt·Summary·M.C Table의 열 구조가 이때 잡히므로, 이 단계를 건너뛰면 행 추가가 안 됩니다.
- **📥 참조 엑셀 다운로드** — 직접 작성하고 싶을 때. 받아서 채운 뒤 **화면에 끌어다 놓으면** 같은 결과가 됩니다.

> 참조 엑셀은 2026-11-04부터 **사내 NAS**(`Reference/Reference.xlsx`)에서 받습니다.
> 서식을 고쳐야 한다면 **NAS의 그 파일 한 개**만 고치면 모두에게 반영됩니다.


### 3-1. 열기 · 저장

- **열기**: 📁 프로젝트 ▸ 📂 프로젝트 열기
- **저장**: 📁 프로젝트 ▸ 💾 프로젝트 저장, 또는 **상단 가운데 파일명을 클릭**
- **자동 저장**: 1분마다 자동으로 저장된다

### 3-2. 복원 (백업)

📁 프로젝트 ▸ **🔄 프로젝트 복원** → 백업 시점 목록이 뜬다.
저장할 때마다 백업이 쌓이므로, 잘못 덮어썼다면 여기서 되돌린다.

### 3-3. 변경 이력

- Gantt 표 아래 **▶ 🕒 변경 이력 확인**을 누르면 누가·언제·무엇을 바꿨는지 보인다.
- 같은 모양의 이력 박스가 Summary·Customer SPEC·M.C·Address·PARTS·Panel Compare에도 있다.
- **🗑️ 구간 삭제**: 날짜 구간을 고르고 **관리자 비밀번호**를 넣어야 지워진다. 되돌릴 수 없다.

## 4. AI 기능

| 기능 | 어디서 | 설명 |
|---|---|---|
| **AI 업무 분석** | 🤖 AI 도구 ▸ 🤖 AI 업무 분석 | 메일을 읽어 간트 업무로 만들어 준다 |
| **AI 업무 보관함** | 🤖 AI 도구 ▸ 📦 | 자동 배치에 실패한 업무가 모인다. 여기서 프로젝트로 보낸다 |
| **AI 요약** | 🤖 AI 도구 ▸ 🤖 AI 요약 | 지금 프로젝트를 요약 |
| **AI 문답** | 🤖 AI 도구 ▸ 💬 AI 문답 | SAP 조회·그룹웨어·사내 자료를 말로 물어본다 |

> ⚠️ **AI는 각자 본인 키를 쓰고, 무료 키는 하루 한도가 있다.** 한도를 넘기면 분석이 멈춘다.
> 한도가 의심되면 AI 분석 설정에서 사용량을 먼저 확인한다.
>
> ⚠️ **쓰기(기안 작성·메일 발송 등)는 AI가 혼자 실행하지 않는다.** 초안을 만들고 사람이 한 번 확인한다.

## 5. 설정 (5구역)

> 2026-11-04에 **성격별로 묶었다.** 예전엔 12개가 한 줄로 섞여 있어 찾기 어려웠다.

| 구역 | 항목 | 설명 |
|---|---|---|
| 👤 **계정·저장소** | 👥 내 팀 | 이 PC가 속한 팀. 프로젝트가 저장되는 팀 폴더를 정한다 |
| | 🔑 로그인·저장소 설정 | NAS·SAP·그룹웨어·인사관리 계정을 한곳에서 |
| | 🔑 비밀번호 변경 | 삭제·보안 동작에 쓰는 **관리자 비밀번호** |
| 🔔 **알림** | 🟢 자동알람 ON/OFF | 알람 자동 발송 켜기/끄기 |
| | ⚙️ 자동알람 설정 | 보내는 서버·받는 서버·참조인·발송 시각 |
| 📬 **메일** | 🟢 메일 완전자동 | 메일을 받아 간트까지 자동으로 넣을지 |
| | 📬 메일 자동배치 설정 | 수집 주기·우선순위 |
| 🗓️ **일정** | 🗓️ 휴일 등록 | 일정 계산에서 빼는 날 |
| 🛠 **진단·도움말** | 🧾 SAP·AI 이슈 리포트 | 팀원들이 겪은 오류가 모인다 |
| | ⌨️ 키보드 단축키 | 단축키 목록 |

> 💡 **"자동로그인"과 "사용자 추가"가 안 보이는 건 정상이다.** 둘 다 구글 드라이브 전용이라,
> 저장소가 NAS인 지금은 눌러도 아무 일이 일어나지 않아 숨겨두었다.

## 6. 자주 막히는 곳

| 증상 | 원인 | 할 일 |
|---|---|---|
| 프로젝트 목록이 비어 있다 | 백엔드가 꺼졌거나 NAS 미로그인 | 백엔드 실행 → ⚙️ 설정 ▸ 🔑 ▸ NAS 확인 |
| 목록은 뜨는데 **색이 전부 같다** | 그 프로젝트를 아직 한 번도 저장하지 않음 | 한 번 저장하면 테마색이 돌아온다 |
| 알람이 "인증 실패"라고 한다 | 저장된 메일 비밀번호가 옛날 것 | 자동알람 설정에서 계정을 다시 저장 |
| 새 프로젝트에서 Customer SPEC **표준 서식이 비어 있다** | 백엔드가 꺼져 NAS의 참조 엑셀을 못 받았다 | 백엔드를 실행한 뒤 마법사를 다시 연다 |
| 아이콘이 □로 깨진다 | JS 문법 오류 | 개발자에게 알린다 (`CLAUDE.md` 참고) |
| 휴대폰에서 안 열린다 | 백엔드가 PC에만 있다 | PC에서 연다 |
