## 1. 시작하기

### 1-1. 무엇이 필요한가

| 필요한 것 | 왜 | 없으면 |
|---|---|---|
| **백엔드가 켜져 있어야 함** (`kortek_backend.bat`) | 저장소(NAS)·메일·SAP·그룹웨어가 전부 이 프로그램을 거친다 | 프로젝트를 **아예 못 연다** |
| **NAS 계정** (아이디·비밀번호) | 2026-11-04부터 데이터는 사내 NAS에 저장된다 | 프로젝트 목록이 비어 보인다 |
| **PC** | 백엔드가 PC에서만 돈다 | 📱 휴대폰에서는 쓸 수 없다 |

처음 설치는 설치 안내 맨 위 **[⬇️ 설치 파일 받기]** → 받은 `kortek_setup.bat` 더블클릭.

### 1-2. 처음 한 번만 — NAS 연결

1. 상단 **⚙️ 설정 ▸ 🔑 로그인·저장소 설정**
2. **NAS** 탭 ▸ **🚀 간편 전환**
3. 아이디·비밀번호 두 칸만 넣으면 계정 저장 → 로그인 → 앱 폴더 찾기까지 자동으로 진행된다.

> ⚠️ **비밀번호를 틀리면 3번까지만 시도한다.** 그 이상은 NAS가 이 PC의 접속을 막을 수 있어
> 앱이 먼저 멈춘다. 막혔다면 비밀번호를 확인한 뒤 백엔드를 다시 시작한다.

### 1-3. 앱을 열면

- 백엔드가 켜져 있고 NAS에 로그인돼 있으면 **프로젝트 불러오기 창이 자동으로 한 번** 뜬다.
- 목록은 **팀 ▸ 담당자 ▸ 프로젝트** 3단으로 접혀 있다. 프로젝트 줄을 누르면 열린다.
- **팀** 줄 오른쪽의 **"전체 N개 열기"** 를 누르면 그 팀 프로젝트를 한꺼번에 연다(탭으로 쌓인다).

## 2. 화면 구조

### 2-1. 상단 메뉴 3개

| 메뉴 | 들어 있는 것 |
|---|---|
| **📁 프로젝트** | 열기 / 저장 / 복원 / 엑셀 저장 / 새 프로젝트 / 삭제 / 자료 전체 내보내기(zip) |
| **🤖 AI 도구** | AI 업무 분석 · AI 업무 보관함 · AI 요약 · AI 문답 · AI 분석 설정 |
| **⚙️ 설정** | 계정·저장소 / 알림 / 메일 / 일정 / 진단·도움말 ([7장](#7-설정-5구역) 참고) |

상단 가운데에는 **지금 열려 있는 프로젝트 파일명**이 보인다. **이 이름을 클릭하면 저장된다.**

### 2-2. 왼쪽 사이드바 — 탭 11개

왼쪽 위 **☰** 로 사이드바를 접었다 펼 수 있다.

| 탭 | 하는 일 |
|---|---|
| 📒 **Project list** | 제품(모델) 전수 목록. 팀별로 관리 |
| 📝 **Summary** | 프로젝트 개요·담당자·개발 단계 일정 |
| 📐 **Customer SPEC** | 고객 사양. **제품구분자(모델)별로 따로** 보관 |
| 🧱 **BOM** | SAP BOM 조회·전개 |
| ⚡ **PARTS** | 주요자재 구분별 비교표(패널·터치 등) |
| 💰 **M.C Table** | 원가·견적표 (Revision별) |
| 📊 **Gantt chart** | 일정 본체 |
| 📅 **Calendar** | 월간/주간 달력 |
| 📋 **Weekly Report** | 주간 업무 보고 |
| 🔔 **Alarm/Notice** | 알람·공지 발송 |
| 🪪 **Address** | 주소록 (팀 공용) |

### 2-3. 탭마다 오른쪽 위에 있는 공통 버튼

생김새는 같아도 **지금 보고 있는 탭의 데이터**를 다룬다.

| 버튼 | 하는 일 |
|---|---|
| **📊 엑셀 저장** | 이 탭 내용을 엑셀로 내보낸다 |
| **📂 불러오기** | 내보낸 엑셀을 고쳐서 다시 넣는다 (**통째로 교체**) |
| **📁 NAS** | 이 탭 전용 사내 NAS 자료실을 연다 (열기·올리기) |
| **🖨️ 인쇄 (PDF)** | 이 탭을 인쇄하거나 PDF로 저장 |

> 💡 **엑셀 왕복**(출력 → 엑셀에서 수정 → 다시 불러오기)이 이 앱의 기본 수정 방식 중 하나다.
> 단 Calendar·Weekly Report·Alarm은 **다른 탭에서 만들어지는 화면**이라 되돌려 넣지 않는다
> (그래서 📂 불러오기가 없다).

> ⚠️ **불러오기는 그 탭을 통째로 바꾸고, 확인 창은 뜨지 않는다.** 대신 바로 옆에
> **↩️ 되돌리기** 버튼이 생기므로, 잘못 넣었으면 그걸 누른다(한 단계만 되돌아간다).
> 우리가 내보낸 엑셀이 아니거나 아예 다른 양식이면 그때는 **AI가 매핑한 뒤 미리보기로 물어본다.**
>
> ⚠️ **내보내기 전에 그 탭을 한 번 열어 둘 것.** PARTS처럼 화면을 보고 표를 만드는 탭은
> 한 번도 들르지 않은 상태에서 내보내면 내용이 덜 나온다(실측: 29행 → 탭을 연 뒤 38행).

## 3. 프로젝트 다루기

### 3-1. 새 프로젝트 만들기

📁 프로젝트 ▸ **➕ 새 프로젝트 추가** → 마법사가 뜬다.

- **🚀 자동으로 가져오기** — 사내 NAS의 참조 엑셀을 바로 불러와 화면에 반영한다.
  Gantt·Summary·M.C Table의 **열 구조가 이때 잡히므로**, 이 단계를 건너뛰면 행 추가가 안 된다.
- **📥 참조 엑셀 다운로드** — 직접 작성하고 싶을 때. 받아서 채운 뒤 **화면에 끌어다 놓으면** 같은 결과가 된다.

> 참조 엑셀은 2026-11-04부터 **사내 NAS**(`Reference/Reference.xlsx`)에서 받는다.
> 서식을 고쳐야 한다면 **NAS의 그 파일 한 개**만 고치면 모두에게 반영된다.

### 3-2. 열기 · 저장

- **열기**: 📁 프로젝트 ▸ 📂 프로젝트 열기
- **저장**: 📁 프로젝트 ▸ 💾 프로젝트 저장, 또는 **상단 가운데 파일명을 클릭**
- **자동 저장**: 1분마다 자동으로 저장된다

### 3-3. 복원 (백업)

📁 프로젝트 ▸ **🔄 프로젝트 복원** → 백업 시점 목록이 뜬다.
저장할 때마다 백업이 쌓이므로, 잘못 덮어썼다면 여기서 되돌린다.

### 3-4. 변경 이력

- Gantt 표 아래 **▶ 🕒 변경 이력 확인**을 누르면 누가·언제·무엇을 바꿨는지 보인다.
- 같은 모양의 이력 박스가 **Summary · Customer SPEC · M.C Table · Address · PARTS · Panel Compare** 에도 있다.
- **🗑️ 구간 삭제**: 날짜 구간을 고르고 **관리자 비밀번호**를 넣어야 지워진다. **되돌릴 수 없다.**

## 4. 탭별 사용법

> 아래 버튼 목록은 실제 화면에서 읽은 것이다(프로젝트를 연 상태, 2026-11-04).
> 공통 버튼(📊 📂 📁 🖨️)은 [2-3](#2-3-탭마다-오른쪽-위에-있는-공통-버튼)에서 설명했으므로 여기선 생략한다.

### 📒 Project list

제품(모델) 전수 목록. **팀별로 따로** 관리된다.

- **➕ 행 추가** / **↺**(되돌리기) / **📥 엑셀 불러오기**
- **열 묶음 체크박스** — 기본 / 담당 / 패널 / 광학 / 전원 / 주요자재 / 케이블 / 터치 /
  기구·포장 / 인증 / 판매량. **체크한 묶음만** 표에 나온다(열이 많아 전부 띄우지 않는다).
  처음엔 기본·담당·패널만 켜져 있다.
- **🔁 열** — 그 체크 상태를 **기본값으로 되돌린다**(묶음을 고르는 버튼이 아니다).
- **NO 숫자를 클릭**하면 행 메뉴(위·아래 이동, 추가, 삭제, 📌고정)가 열린다.
- 검색창에 치면 걸러진다.

### 📝 Summary

프로젝트 개요와 **개발 단계별 일정**(RFQ·PROTO A·PROTO DR·MP·ES·DVR·PRA 등)을 한 화면에서 본다.

- **🔄 Gantt 실적 연동** — Gantt 탭의 실제 일정을 Summary의 단계 날짜로 끌어온다.
- **+ 모델 추가** — 제품구분자(모델)를 늘린다. 이 모델 구분은 **Customer SPEC·M.C Table·BOM과 공유**된다.
- **▲ ▼** 로 항목 순서를 바꾼다.

### 📐 Customer SPEC

고객 사양표. 위쪽 **모델 선택 드롭다운**으로 제품구분자를 바꾸면 그 모델의 사양으로 갈아낀다.

- **🔽 펼치기** — 접힌 항목을 모두 편다.
- 표준 서식(항목 목록)은 새 프로젝트를 만들 때 참조 엑셀에서 들어온다.

### 🧱 BOM

- **🔄 SAP 조회** — SAP에서 BOM을 다단계로 전개해 가져온다.
- 열: 레벨 / 구성부품 / 구성부품내역 / 자재내역2 / Loc.(설치지점) / 수량 / 단위 / KRW / USD /
  상태 / Group2 / 제조사 / 담당자
- **▸ ▾** 로 계층을 접고 편다. **행을 클릭하면** 그 부품을 조회한다.

> ⚠️ **화면과 엑셀은 같은 "지금 보이는 상태"를 쓴다.** 접어 둔 채로 엑셀을 저장하면 **접힌 그대로** 나온다.

### ⚡ PARTS

주요자재 구분(PANEL·TOUCH 등)별 **비교표**. 왼쪽 위 드롭다운(예: 🖥️ PANEL▾)으로 구분을 바꾼다.

- **▼ SPEC / ► BOM** — 사양 비교표와 BOM 중 무엇을 볼지
- **➕ 추가** — 비교표에 부품을 더하는 창을 연다(파일에서 읽어오는 방법도 이 창 안에 있다).
- **🔄** — 그 구분의 **BOM을 SAP에서 가져온다**.
- 항목마다 **✏️(수정) 🗑(삭제)**
- 부품명 옆 **📜 숫자** — 그 부품 이름으로 찾은 NAS 사양서 개수. 누르면 문서를 연다.

### 💰 M.C Table

원가·견적표.

- **R1** — 누를 때마다 **금액이 입력된 리비전끼리 순환**한다. 완전히 새 리비전은 **➕** 로 추가한다.
- **VS** — 비교 화면(Comparison)을 연다.
- **➕ / ✏️ / 🗑️** 로 행을 더하고 고치고 지운다.
- ⚠️ **금액삭제** — 금액을 **전체** 삭제한다(그 행만이 아니다).
- 위쪽 모델 드롭다운으로 제품구분자를 바꾼다.

### 📊 Gantt chart

일정 본체.

- **🎛️ 업무필터 ▾** — LEVEL(WBS) · 업무상태 · 개발단계로 거른다.
- **🛠️ 일정 도구** — 계획 저장·비교 / 선택 구간 재계산 / 날짜순 정렬.
- **🔍 AI검색** — 간트 안에서 키워드로 찾는다(`Ctrl+Shift+F`).
- 업무명 왼쪽 **▶** 로 하위 업무를 접고 편다.
- 표 아래 **▶ 🕒 변경 이력 확인**.
- 키보드만으로 셀을 옮겨 다니며 편집할 수 있다 → [5장](#5-키보드-단축키)

### 📅 Calendar

- **월 / 주** — 보기 전환. **◀ 이전 / 다음 ▶ / 오늘** 로 이동.
- **LEVEL(WBS) ▾** — 어느 레벨의 업무까지 달력에 띄울지.
- **📌 핀셋 업무** — 핀셋 표시한 업무만 본다.
- **🏢 그룹웨어 일정 / 📊 Gantt 일정** — 달력에 무엇을 띄울지 바꾸는 토글이다.
  **버튼 글자와 색은 "지금 보고 있는 것"을 가리킨다** — `🏢 그룹웨어 일정`이라고 적혀 있으면
  지금 그룹웨어 일정을 보는 중이고, 누르면 `📊 Gantt 일정`(간트 업무)으로 바뀐다.
  그룹웨어 일정은 처음 켤 때 한 번 불러오고 2분간은 다시 부르지 않는다.
- **📤 내보내기/동기화** — 달력 일정을 내보낸다.

### 📋 Weekly Report

- **◀ 이전주 / 다음주 ▶ / 오늘** 로 주를 옮긴다.
- **LEVEL(WBS) ▾** — 보고에 넣을 업무 레벨.
- 메일에서 온 업무에는 **📧 원문 보기**가 붙어 원본 메일을 볼 수 있다.

#### 📥 PPT 출력 — 창이 두 번 뜬다

1. **🎨 테마 색상 고르기** — `기본 테마 색상 출력` / `현재 테마 색상 출력` / `취소`.
   (여기서 취소하면 아무 파일도 안 만든다)
2. **✍️ 내용 미리보기** — 이번 주/다음 주/이슈 내용을 **고칠 수 있는 칸**으로 보여준다.
   - **💾 PPT 저장** — 칸에 보이는 내용 그대로 파일을 만든다.
   - **취소 (직접 출력)** — ⚠️ **이름과 달리 출력을 한다.** 칸을 고치지 않고 원본 그대로 낸다.
     진짜로 그만두려면 오른쪽 위 **✕** 를 누른다.
   - AI 키가 있으면 이 단계에서 AI가 내용을 다듬어 준다. 키가 없으면
     **"⚠️ AI 키 없음 — 원본 데이터로 초기화됨"** 이라고 뜨고 원본 그대로 쓴다(정상이다).
3. 파일은 `<프로젝트명>_주간보고.pptx` 로 저장된다 (슬라이드 2장).

### 🔔 Alarm/Notice

- **🔔 Alarm▾** — 알람 종류 선택.
- **📧 일괄 발송 / 📤 선택 발송** — 알람 메일을 보낸다.
- 보내는 계정·시각은 ⚙️ 설정 ▸ **자동알람 설정**에서 정한다.

### 🪪 Address

팀 공용 주소록. 열: 이름 / 영문 이름 / 부서 / 직함 / 이메일 / 휴대폰 / 근무처 전화 / 텔레그램 ID.

- 이 주소록이 **이름 자동완성**과 **텔레그램 발송 대상**의 기준이 된다.
- 아래쪽에 **▶ 🕒 변경 이력 확인**.

- **🔀 다른 제공사로 자동 전환(교차 폴백)** — 한 곳이 한도에 걸리면 다른 제공사로 넘긴다.

### 7-1. 자동알람 설정

네 구역으로 접혀 있다. 처음엔 전부 접혀 있으니 **▶ 펼치기**를 눌러 연다.

- **📥 처음 사용자 — 설치 안내** — 백엔드 설치 파일 받는 곳.
- **🖥️ 이메일 서버 설정** — 서버 주소 / 포트 / 계정 / 비밀번호, 그리고 **받는 서버**.
  ⚠️ **보내는 서버와 받는 서버는 다른 장비일 수 있다.** 받는 서버 칸을 비우면 기본값을 쓴다.
  계정에 IMAP 권한이 없으면 **"수신(받기)은 POP3만 사용"** 을 체크한다.
- **💬 메신저 서버 설정** — 텔레그램 Bot Token / 내 Chat ID.
  **새 메일 알림**(백엔드가 새 메일을 확인해 요약 발송)을 켜고, **확인 간격(분)** 과
  **조용한 시간**(이 시간대엔 안 보냄)을 정한다.
- **🌐 외부 도메인 발송 허용** — 사외 도메인으로의 발송을 도메인 단위로 체크해 허용한다.
  주소록에 있는 도메인이 자동으로 나열되고, 각 줄에 그 도메인에 속한 사람 수가 표시된다.

### 7-2. 메일 자동배치 설정

- **⏱️ 수집설정** — 수집 주기(10/15/30/60분), **📌 핀셋 기준점수**,
  EOL 프로젝트 포함 여부, 처리된 업무 자동삭제 여부, 토픽 프로파일 자동 생성 끄기
  (무료 API 한도가 빠듯할 때 끄면 좋다).
- **⭐ 가산점수** — 메일 우선순위를 정하는 점수표.
  - **🚨 점수 가산 키워드** — 키워드와 점수를 짝으로 추가한다.
  - **📊 우선순위 점수** — 외부(고객사) 발신 / To(직접수신) / Cc(참조) / 중요도 헤더 가산점.
  - **👤 직급별 점수** — 보낸 사람 직급별 가산점(회장·이사·본부장·팀장·사원 등).
- **🚫 자동폐기 필터** — 아예 버릴 메일 조건.

## 8. 외부 시스템 연동

| 시스템 | 무엇에 쓰나 | 연결 확인 |

| **그룹웨어** | 일정·메일·게시판·전자결재 기안 | 전용 크롬이 로그인돼 있어야 한다 |

> ⚠️ **로그인 실패는 재시도하지 않는다.** SAP·그룹웨어·인사관리·NAS 모두, 실패하면 그 자리에서
> 멈추고 사람에게 알린다. 자동으로 다시 시도하면 **사내 계정이 잠기기 때문**이다.
> 막혔다면 비밀번호를 확인하고 백엔드를 다시 시작한다.
