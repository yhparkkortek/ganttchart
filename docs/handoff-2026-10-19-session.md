## 3. 알아둘 것 (문서에 안 적힌 것들)

- **BOM 헤더는 폭 예산이 빡빡하다.** 필요 1023px / 사이드바 편 1280창 가용 1030px — 여유 7px뿐.
  `flex-wrap: nowrap`이라 행이 바뀌는 게 아니라 **flex가 버튼을 찌그러뜨려 라벨이 2줄로 깨진다.**
  요소를 추가하려면 **다른 칸을 줄일 것**. 버튼엔 `white-space:nowrap`이 걸려 있다.
- **정렬이 켜진 동안에는 가지별 `▾` 토글이 렌더되지 않는다**(이번 변경과 무관한 기존 동작).
  상단 "접기/펼치기" 버튼은 정렬 중에도 동작하고 결과가 바로 반영된다. 가지별 토글까지
  필요해지면 정렬 분기에 삼각형을 그려 넣어야 한다.
- **ALV 상한을 2000보다 더 올리려면 먼저 잴 것.** `t(n) ≈ 25초 + 0.013 × n` 이라 4000행이면
  ≈77초로 타임아웃 90초에 거의 붙는다. 측정용 환경변수 `KORTEK_GRID_ROW_CAP` 있음.

## 4. 되풀이하지 말 것 — 이 세션에서 실제로 당한 함정

- **PowerShell 훅의 한국어는 UTF-8을 강제해야 한다.** 이 PC의 `[Console]::OutputEncoding`이
  **cp949**라 그냥 두면 차단 메시지가 깨져 Claude Code가 못 읽는다.
  `[Console]::OutputEncoding = [System.Text.UTF8Encoding]::new($false)`
- **`python -I`는 `PYTHONIOENCODING`까지 무시한다.** 한국어를 찍는 내 스크립트엔 `-I`를 쓰지 말 것
  (`-I`는 신뢰할 수 없는 디렉터리에서 인터프리터를 돌릴 때 쓰는 것).
- **Bash heredoc이 백슬래시를 먹는다.** 정규식·Windows 경로가 든 코드는 **Write/Edit 도구로** 쓸 것.
  (슬래시 경로를 쓰면 애초에 안 걸린다 — PowerShell도 `C:/...`를 받는다.)
- **진단 스크립트가 비밀번호를 찍지 않게.** 입력칸을 덤프할 때 `el.value`를 담으면 비밀번호가
  그대로 파일에 남는다(실제로 한 번 남겨서 즉시 지웠다). **길이만** 찍을 것.
- **git 작업본에서는 `/self-check-update`가 `devMode`로 건너뛴다**(`.git` 유무로 판정).
  이 PC에선 그 엔드포인트로 배포 검증이 안 되니, GitHub raw를 직접 받아 대조할 것.
- **CDP 클릭은 최소화된 창에서 조용히 빗나간다.** 합성기 히트테스트 대상이 없어서인데,
  오류도 네트워크 요청도 안 나간다. 좌표를 **재기 전에** 창을 `normal`로 돌릴 것
  (복원하면 뷰포트가 바뀌어 버튼 위치도 달라진다 → 복원 → 측정 → 클릭 순서).
