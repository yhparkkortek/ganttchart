## 📌 아직 확인 못 한 것

아래는 **직접 끝까지 돌려보지 못한** 것들이다. 쓰기 전에 한 번 확인할 것.

> ⚠️ **6-A ~ 6-E 장은 "무엇이 있고 어디 있는가"까지만 확인한 것이다.**
> 화면과 앱의 기능 목록(SAP·앱 조작·기안 양식·NAS 폴더)을 직접 읽어 적었지만,
> SAP 조회·기안·자재청구를 **실제로 실행해 보지는 않았다**. 예시 문장은 앱에 등록된
> 그대로이므로 말은 맞지만, 결과 화면까지 본 것은 아니다.

- **SAP 실제 조회·쓰기** — 자재/가격/재고, BOM 조회, 자재 보관함(MB21·ZMM019), 구매오더,
  입고처리(ZMM062). SAP GUI를 띄우고 실제 트랜잭션을 돌려야 해서 이번엔 건드리지 않았다
  (계정 설정이 있는 것까지만 확인).
- **그룹웨어 쓰기** — 전자결재 기안 작성, 메일 발송, 일정 등록, 회의실 예약.
  (조회는 전부 확인했다 — 아래 참고. 쓰기는 사내에 실제로 글·메일·예약이 생기므로 안 했다)
- **인사관리(kInsa)** — 근무계획 신청서 칸 채우기. (설정됨·접근 가능까지만 확인, 로그인 안 함)
- **메일 실제 송수신** — POP3 수집, 알람 발송, 텔레그램 알림. 실제로 메일이 나가므로 돌리지 않았다.
- **엑셀에서 칸 값을 고쳐서** 넣어 보기 — 행을 더하고 지우는 것까지는 확인했지만(아래 참고),
  값을 바꿔 넣었을 때 화면에 제대로 반영되는지는 아직 눈으로 안 봤다.
- **AI 기능 실제 호출** — 무료 키 하루 한도를 쓰게 되므로 호출하지 않았다(설정 화면만 확인).
- **모바일 실기기** — 아래 "확인한 것" 참고. 브라우저 에뮬레이션으로만 봤다.
