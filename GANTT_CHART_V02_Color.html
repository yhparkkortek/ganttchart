❓ 구글 캘린더 자동 동기화 설정 방법 ✖
1단계. GitHub 토큰 준비 (최초 1회만)
  1. github.com/settings/tokens 접속 (GitHub 로그인 필요)
  2. Generate new token → Generate new token (classic) 클릭
  3. Note: 아무 이름(예: gantt-sync), Expiration: No expiration 권장
  4. 권한(Scopes)은 gist 항목 하나만 체크
  5. Generate token 클릭 → 나오는 토큰(ghp_로 시작)을 복사해서 잘 보관 (다시 볼 수 없음)
2단계. 앱에서 동기화 실행
  1. 캘린더 탭에서 🔗 자동 동기화 버튼 클릭
  2. 토큰 입력창이 뜨면 1단계에서 복사한 토큰 붙여넣기 (최초 1회만 물어봄)
  3. 완료되면 주소창(https://gist.githubusercontent.com/...)이 표시됨 → 전체 복사
3단계. 구글 캘린더에 등록 (최초 1회만)
  1. calendar.google.com 접속
  2. 왼쪽 사이드바 다른 캘린더 옆 [+] 클릭
  3. URL로 만들기 선택
  4. 2단계에서 복사한 주소 붙여넣고 캘린더 추가
이후에는?

데이터가 바뀔 때마다 🔗 자동 동기화 버튼만 다시 누르면 됩니다. 구글 캘린더 등록은 최초 1회만 하면 되고, 주소도 그대로 유지됩니다. 구글 쪽 반영은 보통 8~24시간 정도 걸릴 수 있습니다.

⚠️ 토큰은 비밀번호와 같으니 다른 사람과 공유하지 마세요. 이 링크(gist 주소)를 아는 사람은 누구나 일정 내용을 볼 수 있으니, 민감한 프로젝트라면 사용을 신중히 결정하세요.
