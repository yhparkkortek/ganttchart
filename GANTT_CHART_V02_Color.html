⚙️ 알람 설정

📥 처음 사용자 — 설치 안내 ▶ 펼치기
⚙️ Backend 설치 (Step 1~4)
📱 Telegram (Step 5)
🌐 Chrome 브라우저 사용을 권장합니다. IE · Edge에서는 메일 가져오기 등 일부 기능이 동작하지 않을 수 있습니다.
Step 1. Python 설치 python.org →
　　설치 시 "Add Python to PATH" 체크 필수 (미체크 시 서버 실행 안 됨)

Step 2. KORTEK Backend 파일 설치
　　⬇️ kortek_backend.zip 다운로드
　　→ 압축 풀기 → 파일 2개 확인 (kortek_backend.py / kortek_backend.bat)

Step 3. kortek_backend.bat 더블클릭
　　→ 최초 실행 시 패키지 자동 설치 (1~2분 소요, 이후엔 바로 실행)
　　→ 검은 창에 http://127.0.0.1:5000 이 보이면 준비 완료 ✅
　　→ 검은 창은 최소화해두세요 (닫으면 서버 종료됨)

Step 4. 앱 사용 중에는 검은 창(서버)을 닫지 마세요
　　→ 창을 닫으면 메일 발송·수신·Telegram 알람이 모두 중단됩니다.

💡 PC 켤 때마다 서버 자동 시작 설정 (선택)
　　① kortek_backend.bat 파일 우클릭 → [바로가기 만들기]
　　② 키보드 Win + R → 열기 창에 shell:startup 입력 → Enter
　　　 (Windows 시작 프로그램 폴더가 열립니다)
　　③ 열린 폴더에 ①의 바로가기 붙여넣기
　　→ 이후 PC를 켤 때마다 백엔드 서버가 자동으로 시작됩니다 ✅
💡 Telegram 알람을 받으려면 Bot Token과 Chat ID 2가지가 필요합니다.
　Bot Token = 알람을 보내는 봇 계정 · Chat ID = 알람을 받을 내 계정 번호
PM 5-1. 텔레그램 앱 설치
　　telegram.org →　에서 PC 또는 모바일에서 설치

PM 5-2. Bot Token 발급 (@BotFather)
　　① 텔레그램에서 @BotFather 검색 후 시작
　　② /newbot 입력 → 봇 이름 입력 (예: KORTEK Alarm)
　　③ 봇 사용자명 입력 (영문, _bot으로 끝나야 함 · 예: kortek_alarm_bot)
　　④ BotFather가 Token (긴 문자열)을 발급 → 복사해두기
　　⑤ 발급된 봇 링크(t.me/봇이름)를 팀원에게 공유 → 각자 /start 전송 요청

팀원 5-3. Chat ID 확인 (@userinfobot)
　　① 텔레그램에서 @userinfobot 검색 후 시작
　　② /start 입력 → 봇이 나의 Chat ID (숫자) 를 알려줌
　　③ 팀원도 동일하게 본인 Chat ID 확인 후 PM에게 전달

PM 5-4. 주소록에 등록 및 저장
　　① 알람 설정 → Telegram 섹션 → Bot Token 입력 후 💾 저장
　　② 주소록 탭 → 팀원 행에 Chat ID 입력
　　③ 📨 테스트 버튼으로 수신 확인 ✅
